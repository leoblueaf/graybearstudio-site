This notice covers the GrayBear Studio websites: graybearstudio.com and research.graybearstudio.com, the site of the Hidden Structure Research Group. Each app has its own privacy policy, linked from that app's page.

## The short version

This website does not use cookies, analytics, advertising or tracking of any kind. We do not ask for your name or email address, and there is no sign-in. The one exception is the Hitherto Prayer Quilt, described below.

## What happens when you visit

Like every website, pages are delivered by servers that see basic technical information about the request, such as your IP address, browser type and the page asked for.

- **Hosting.** The site is hosted on GitHub Pages. GitHub may record visitors' IP addresses for security and to keep the service running, as described in the GitHub Privacy Statement.
- **Fonts.** The site's fonts load from Google Fonts, so your browser contacts Google's servers, which receive your IP address and browser details. Google's handling of this is described in the Google Privacy Policy. Both receive only what any website receives (your IP address and browser details), and both publish terms that protect it at least as strongly as this notice does, so it receives the same or equal protection.

We do not receive or keep these records ourselves.

## The Hitherto Prayer Quilt

The Prayer Quilt pages at [graybearstudio.com/hitherto/quilt/](https://graybearstudio.com/hitherto/quilt/) work differently from the rest of this site. They load Google Firebase and Google reCAPTCHA so people can add squares and tie knots, and they give each browser a random ID when it does. They have their own [privacy notice](https://graybearstudio.com/hitherto/quilt/privacy/), which explains exactly what they store.

## If you email us

If you write to one of our addresses, we receive your email address and whatever you include in the message. We use it only to reply and to help with your question, and we do not add you to any mailing list.

## Children

This website is not directed to children under 13.

## Changes

If this notice changes, we will update this page and the date above. If we ever add visitor statistics, this page will say so before they are turned on.
